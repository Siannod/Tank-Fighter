<h1>Tank Fighter</h1><br>
<h2>Overview</h2><br>
I made tank fighter as an initial project using Unreal Engine 5.6; the development of the game was focused more on creating gameplay mechanics rather than refining and optimising those mechanics
<h2>Controls</h2><br>
WASD - Movement<br>
1 2 3 4 - Select weapon<br>
LMB - Fire Weapon<br>
SPACE - Dash<br>
